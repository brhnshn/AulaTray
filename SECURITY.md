# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability in AulaTray, please do **not** report it via a public GitHub issue.

Instead, please send an email or open a private security advisory on GitHub with:
- Description of the issue
- Steps to reproduce
- Potential impact

We will investigate and respond promptly.
